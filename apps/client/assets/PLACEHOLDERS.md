# 发行候选中的素材占位

当前 `assets/` 不分发原始图片、SVG 图形、音频或视频。全部媒体文件均为本项目本轮程序生成的中性占位：

- 224 个 PNG/JPEG/WebP：自制透明空心框或单色底，保留文件格式和原图像素尺寸；没有复制原始像素或元数据。
- 22 个 SVG：自制单一空心矩形，保留对应画布尺寸；不包含原图路径、内嵌图像或外链。
- 60 个 MP3 和 2 个 WAV：合成静音，保留文件格式、采样率、声道及近似时长。
- 1 个 MP4：合成单色画面及静音，保留格式、分辨率、帧率和近似时长。

占位让现有静态引用和构建可继续，但**不等于原有 UI 美术、故事画面、背景音乐、音效或动画体验完整**。若需要可用素材，由部署者提供自己有权使用和分发的文件，并保持对应路径、格式与尺寸约束。外部素材功能需显式配置 `EXPO_PUBLIC_APP_STATIC_BASE`；缺省只显示透明占位。

占位图片和声音的使用说明不覆盖程序依赖所包含的第三方字体、图标库、SDK，也不构成对项目名称、商标、故事文本或外部资源的授权。相关权利需分别确认。原媒体与其哈希映射仅保存在发行目录之外的私有备份中，不进入本候选。
