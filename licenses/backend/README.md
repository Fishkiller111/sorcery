# 后端镜像第三方许可材料（预览）

本目录包含后端所使用的第三方 Go 模块、Go 运行时、CA 和时区数据的许可证、NOTICE 和必要的第三方源码包。所附源码仅属于相应第三方组件，**不包含 Sorcery 私有后端源码**。

空库 scratch 预览镜像 `ghcr.io/fishkiller111/sorcery-backend:0.1.0-preview` 已公开，仅支持 linux/arm64；manifest digest 为 `sha256:ebc8897f11ede32755cdf0df6d5aaf91ca96717831392fd25a22beacab5d9e66`。这些第三方材料基于候选构建快照，不能仅凭镜像公开推断最终镜像的每项依赖、资源版本和哈希均已复核；具体核验范围和限制见各子目录 README。后端自有二进制使用条款见 [DISTRIBUTION-TERMS.md](DISTRIBUTION-TERMS.md)。
