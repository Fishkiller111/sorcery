# Sorcery 管理后台 — 静态发行候选

此目录只包含编译后的管理端静态文件和许可材料，不包含管理端源码。当前为预览版本，版本适配与发行内容审查仍应以实际发布回执为准。管理端依赖另行提供的兼容后端；静态界面不会自动创建管理员、角色或数据库数据。

## 包含内容

- `static/`：管理端静态资源（131 个文件）。
- `SHA256SUMS`：本目录文件 SHA-256（不含该清单本身）。
- `DISTRIBUTION-TERMS.md`：管理端使用和再分发说明。
- `THIRD-PARTY.md`、`licenses/`：第三方组件清单和原始许可文件。

## 启动与自建

1. 在本目录执行 `shasum -a 256 -c SHA256SUMS`。
2. 将 `static/` 放在自己的静态服务器中，按 SPA 配置路由回退；`/assets/` 文件找不到时应返回 404，避免以 HTML 冒充 JS/CSS。
3. 界面请求同源 `/api/v1/` 与 `/static/`，需通过自己的反向代理将这两个路径转发至兼容后端；这不是可在页面中设置的任意 API 地址。仅监听回环地址的 Nginx 配置示意（自行替换路径、端口）：

```nginx
server {
    listen 127.0.0.1:8088;
    root /ABSOLUTE/PATH/TO/static;
    index index.html;
    location ^~ /api/v1/ { proxy_pass http://127.0.0.1:8888; }
    location ^~ /static/ { proxy_pass http://127.0.0.1:8888; }
    location ^~ /assets/ { try_files $uri =404; }
    location / { try_files $uri $uri/ /index.html; }
}
```

此示例仅说明路径转发，不包含 TLS、认证网关、访问控制或生产加固，未作为正式 Nginx 配置验收。若后端位于其他容器或主机，应替换上游地址并确保私网连通、TLS/防火墙和身份授权。不同域名部署时不能把后端地址硬编码到已编译 JS；应通过同源代理或自己的网关适配；管理端源代码不随包提供，不能按源码修改后重编译。

4. 在后端以自建流程创建自己的管理员并配置用户、角色、内容和服务；不得依赖默认弱口令。管理端静态包不能代替后端的鉴权、权限控制和任务安全设置。

## 本版本功能限制

为避免把原产品的运营目标带入自建实例，此构建没有设置分享站地址、Telegram 运营用户名或发件邮箱；因此相应深链不会生成，部分邮件操作受限。TG 公告和部分召回写入由管理端固定禁用（取消排队消息或关闭召回仍可操作）。这些是编译期设置，使用者无法仅通过浏览器运行时配置将其开启；更换静态服务器地址也不能解除限制。前端限制可被绕过，不能代替后端鉴权与任务禁用。

## 验证边界

现有 131 个静态文件与隔离构建按 SHA-256 完全一致。历史 Chrome 隔离测试覆盖测试管理员登录、`/dashboard` 与 `/users` 请求；未覆盖所有管理业务、正式反向代理、空库新版本或生产环境。静态 JS 中的 UI 图标及其他第三方代码按其原许可证提供；不包含原项目独立媒体素材。
